把你的圖示檔案放在這個資料夾底下，檔名要對應 index.html 裡 cards 陣列的 img 路徑：

  ticket.png   → 電子票券繳費
  flame.png    → 蝦皮超划算
  3c.png       → 蝦皮3C家電
  cart.png     → 天天補貨日
  fashion.png  → 流行穿搭
  home.png     → 居家生活文創
  mommy.png    → 蝦皮媽咪會員
  world.png    → 海外購物節

建議：128×128px以上、透明底PNG或SVG，檔案還沒放上去之前，
首頁那格會自動顯示「尚未上傳圖示」的佔位框，不會報錯。
